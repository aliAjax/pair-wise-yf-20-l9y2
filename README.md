# 烟花燃放点位复核台

单页复核工作台（React + Vite + TypeScript）：预置 4 个燃放点位与 3 段节目，登记型号、口径、发射角、点火时间、安全距离，按规则自动复核，整场提交放行后同步生成时间轴、点位平面图与型号统计。

## 复核规则

- 相邻点位在**同一音乐时刻**（点火时刻相差 ≤1s）**发射角交叉**且**间距 < 30m** → 双方待复核，不能排片
- 点火时间落在**封锁段**内 → 该点位待复核，不能排片
- **整场提交**：任一点位待复核或节目段落相互重叠 → 拒绝，配点表与进度保持不变
- 放行后：时间轴 / 点位图 / 型号统计同步为放行快照；此后修改配点表会提示"有未提交修改"

## 数据

仅保存在本机浏览器 localStorage（键：`fireworks-review-console:v1`），刷新保留；「重置预置数据」可恢复初始状态。预置数据中点位 B/C 故意构成一组交叉冲突，便于演示复核流程。

## 技术栈

React 19 + Vite 7 + TypeScript
